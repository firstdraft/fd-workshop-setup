WORKSHOP LAPTOP SETUP (Windows or Mac)
======================================

1. Right-click the zip file you downloaded and choose "Extract All...".
   Extract it to your Documents folder.

2. Open Claude Desktop, go to the Code tab, and open the extracted
   "workshop-kit" folder.

3. Type:   Set up my laptop for the workshop

4. Claude will guide you. Your laptop may restart once or twice.
   After each restart: open Claude, open this same folder, and type:  continue
   If you were in the BIOS and could not change the setting, type
   instead:  I could not change the BIOS setting

Before you start:
- Plug in your charger.
- Have your phone nearby (you may need it to look something up while
  the laptop restarts).
- Save and close other work.

If Claude is not working, double-click "Setup WSL without Claude.cmd" instead.

ON A MAC
========

1. Double-click the zip file you downloaded. It unzips into a folder.

2. and 3. are the same as above. There are no restarts.

Claude opens a Terminal window to install Homebrew. When it asks for
your password, type your Mac password there and press Return. Nothing
shows while you type. Claude never asks for your password.
"Setup WSL without Claude.cmd" is for Windows only.

UPDATING FIRST DRAFT LATER
==========================

Windows: download this kit again, open its "workshop-kit" folder in
   Claude Desktop, and type:  continue
   When Claude is done, start a new session in Ubuntu as it shows you.
   On Windows this kit links First Draft's two skills into Ubuntu
   rather than installing the plugin, so running the kit again updates
   them.

Mac: nothing to do. This kit installed First Draft as a Claude plugin
   and turned on its automatic updates. To update at once, follow the
   steps on https://firstdraft.com/update
